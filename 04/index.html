The display property

The CSS dislpay property is used to determine wheather an element is treated as a block/inline element & the layout used for its childrean.
Like: flexbox/ grid etc.

display: inline

Takes only the space required by the element. No linebreaks before and after. Setting width/height/top&bottom -- margin/padding not allowed.

display: block

Takes full space avaliable in width and leaves a newline before and after the element.

display: inline-block

Similar to inline but setting height,width,margin,padding is allowed. Elements can sit next to each other.

display: none v/s visiblity: hidden

With display: none , the element is removed from the document flow. Its space is not blocked.
With visiblity: hidden, the element is hidden but it's space is reversed.

text-aling property

Used to set the horizontal alingment of a text.

text-decoration property

Used to decorate the text. Can be overline,line-through,underline,none.

text-transform property

Used to specify uppercase and lowercase letters in a text.
.cont{text-transform: uppercase;}

line-height property

Used to specify the space between lines.
.small{line-height: 0.7;}

Font

Font plays a very important rolw in the look and feel of a website.

font-family

Font family specifies the font of a text.
Can hold multiple values as a fallback system.
p{font-family: "Times New Roman",monospace;}
