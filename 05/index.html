Size Position & List

There are more unit for describing size other than 'px'. These are rem,em,vw,vh,percentages etc.

What's Wrong With 'px'?

Pixels are relative to the veiwing device, For a device with size 1920x1080, 1px is 1unit of 1080/1920.

Relative Lenghts

These units are relative to the other length property.
Following are some of the most commonly used relative lenghts:
1. em(means it gets multiplied by the no of it's parent size.): Unit relative to the parent of the font size. em means "my parent element's fontsize".
2. rem(means it's root{is html size(16px bt defalult)} value is multiplied by the given number.): Unit relative to the root font size(tag>).
vw/vh(): Unit relative to the 1% viewport width/height.

min/max height/width property

CSS has a min-hight,max-height,min-width,max-width property.
If the content is smaller than the minimum height, minimum height will be applied.
Similar is the case related with the other properties.

The Position Property

Used to manipulate the location of an element.
Following are as possible values:

position: static;

The defalult position. Top/Bottom/Left/Right/z-axis has no effect.

position: relative;

The Top/Bottom/Left/Right/Z-index will now work. Otherwise the element is in the flow of document like static.

position: absolute;

The element is removed from the flow & is relatively positioned to it's first non-static ancestor. top/bottom etc works.

position: fixed

Just like absolute except the element is positioned relative to the browser window.

position: sticky

The element is postitioned based on user's scroll position.

z-index property

The z-index property specifies the stock order of an element.
It defines which layer will be above which in case of overlapping elements.
