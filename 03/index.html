CSS Box Model

The CSS box model loks at all the HTML elements as boxes.

Setting Width & Height

We can set height and width in CSS as follows:
#box{height: 120px;
width: 120px;}

That total height/width is calculated as follows:
Total height = height + top/bottom padding + top/bottom border + top/border margin

Setting Margin and Padding

We can set margin and padding as follows:
.box{ margin: 3px;
padding: 3px;}
As you know margin have four sides then you can also add them by following:
.boxmain{ margin: 2px 4px 6px 2px};
It is of clockwise-direction.
For Top/Bottom and Left/Right as follows:
.main{ margin: 6px(T/B) 4px(R/L)};
You can also do it indivisiually .
Such as margin-top: 12px;

Setting Borders

We can set borders as follows:
.bx{border-width: 2px;
border-style: solid;
border-color: red; / border: 2px solid red;}

Border Radius

We can set border radius to create rounded borders.
.main{border-radius: 12px;}

Margin Collapse

When two margins from different elements overlap, the equivalent margin is the greater of the two. This is called margin collapse.

Box-Sizing

Determines what out of padding and border is included in the element's width and height.
.div{ box-sizing: border-box;}

Can be of Border-box and Content-box.
