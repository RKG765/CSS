Colors & Background

CSS rules are simple key-value pairs with a selector. We can write CSS rules to change color set background.

Color Property

The CSS color property can be used to set the text color inside an element.
Like: p{color: red;}
Similarly we can set color for different elements.

Types Of Color Values

Following are the most commonly used color values in CSS.
1.RGB: Specify color using Red,Green,Blue values.
2.HEX Code: Specify color using hex code. Like--> #ff7180
3.HSL(Hue,Saturation,Lightness):Specify the color using HSL value. Like--> hsl(8,90%,60%)

Note: We also have an RGBA and HSLA values for color but they are rarely used by beginners. A: Aplha.

Backgrounds

Background Color Property

The CSS background-color property specifies the background color of a container.

Background Image Property

It is used to set an image as the background.
The image is by default repeted in x & y directions.

Background Repeat Property

Can be any of:

  • 1. repeat-x --> Repeat in horizontal direction.
  • 2. repeat-y --> Repeat in vertical direction.
  • 3. no-repeat --> Image not repeat.

Background-Size Property

Can be of following:

  1. Cover: Fits no-empty space remains but the image can be blurry if it is of low resolution.
  2. Contain: Fits on the basis of visiblity of image.
  3. auto: Display in orignal size.
  4. {{width}}: Set width and height will set automatically.

Background Position Property

Sets the starting position of a background-image.
div
{background-position: left-top;}

Background-attachment property

Defines a scrollable & non-scrollable character of a background image.
div
{background-attachment: fixed;}
Some imp:
1. Fixed: background-image will be fixed.
2. Scroll: Both will look like scrolling but inner scroll's.
3. Local: Both will scroll.

Background-shorthand Property

A single property to set multiple background-properties.

div
{background: red url('img.jpg') no-repeat fixed right top;}

One of the properties can be missing given the others are in order.
