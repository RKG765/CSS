Flexbox

Before we look into CSS flexbox , we will look into float and clear properties.

The Float Properties

Float properties are simple. It just flows the elements towards left/right.

The Clear Property

Used to clear the float. It specifies what elements can flow beside the given elements.

The CSS Flexbox

Aims at providing a better way to layout , aling and distribute space among items in a container.
.cont{ display: flex; => Initialize a flexbox.}

Flex-direction Property

Defines the direction towards which items are laid can be row(default), row-reverse, column, column-reverse.

Flex Properties For Parents (Flex Container)

Following are the properties for the flex parent:

flex-wrap

Can be wrap, nowrap, wrap-reverse. Wrap items as needed with the property.

justify-content

Defines alingment along main-axis.

aling-items

Defines alingment along cross-axis.

aling-content

Alings a flex contianer's lines when there is a extra space in a cross-axis.

Flex Properties For Children (Flex Items)

Following are the properties for flex children:

Order

Controls the order in which the items appear in the flex container.

aling-self

Allows default alingment to be overridder for the indivisiual flex items.

flex-grow

Defines the ability for a flex item to grow.

flex-shrink

Specifies how much a flex item will shrink relative to the rest of the flex items.
